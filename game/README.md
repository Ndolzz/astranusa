# Direktori game/

Direktori ini ditetapkan sebagai root proyek Godot 4. File `project.godot` beserta seluruh source code, aset, konfigurasi, dan pengujian akan diinisialisasi pada tahap SDD-01 (Repository & CI Foundation).

Ketentuan:

1. Dokumentasi tidak ditempatkan di dalam direktori ini; seluruh dokumentasi berada pada `docs/`.
2. Tidak ada file yang boleh dibuat di direktori ini sebelum spesifikasi SDD-01 disetujui.
3. Struktur internal direktori ini direncanakan pada [Technical Architecture](../docs/TECHNICAL_ARCHITECTURE.md) dan finalnya ditetapkan pada desain SDD-01.
